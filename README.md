SME朋辈顾问咨询预约系统 · 产品功能文档

本系统为经管学院朋辈顾问咨询项目提供线上化的一对一咨询预约能力，覆盖从顾问信息展示、时段排期、预约报名、邮件通知、取消与反馈到数据汇总导出的全流程。

一、平台定位与价值

| 角色 | 价值 |
|---|---|
| 学生侧 | 把“找朋辈顾问咨询”从邮件/微信沟通升级为自助式在线预约，降低协调成本 |
| 管理侧 | 将人工登记表升级为结构化数据，支持批量排期与一键导入/导出，提升运营效率 |
| 顾问侧 | 可通过系统进行排期，并实时查看个人预约情况 |

二、用户角色与权限总览

| 能力 | 学生 | 朋辈顾问 | 管理员 |
|---|---|---|---|
| 账号密码登录后台 | 否 | 是 | 是 |
| CUHK统一身份认证（SSO） | 是 | 是 | 否 |
| 浏览顾问信息 / 预约咨询 / 填写咨询主题 | 是 | 否 | 否 |
| 查看个人预约记录 / 取消预约 | 是 | 否 | 否 |
| 维护个人排期 / 咨询名额 | 否 | 是 | 是 |
| 上传批量排期 / 下载排期模板 | 否 | 是 | 是 |
| 查看个人咨询预约明细 / 填写咨询反馈总结 | 否 | 是 | 是 |
| 查看所有顾问的预约数据 / 导出 | 否 | 是 | 是 |
| 顾问账号管理 / 预约全量查询与导出 / 统计分析 | 否 | 否 | 是 |

三、时间规则

| 规则 | 取值 |
|---|---|
| 同周预约限制 | 无 |
| 报名截止时间 | 咨询开始前24小时 |
| 学生自助取消截止 | 咨询开始前4小时内禁止取消 |
| 顾问取消预约 | 咨询开始前4小时内禁止取消 |

四、功能模块详述

模块A：登录与认证

| 角色 | 方式 |
|---|---|
| 管理员 | 用户名 + 密码登录 |
| 朋辈顾问 | CUHK统一身份认证SSO登录，首次登录自动建档，无需注册 |
| 学生 | CUHK统一身份认证SSO登录，首次登录自动建档，无需注册 |

模块B：学生端

B-1：顾问信息浏览

- 展示所有朋辈顾问基本信息（照片、姓名、年级、专业、擅长方向、个人简介）

- 支持按专业 / 擅长方向筛选

- 每位顾问卡片上展示近期可预约时段

B-2：预约咨询（核心流程）

- 选择顾问 → 2. 选择时段 → 3. 填写咨询信息 → 4. 提交确认

咨询信息填写字段：

| 字段 | 说明 | 是否必填 |
|---|---|---|
| 咨询主题 | 简要描述咨询方向（如选课建议、升学规划、考试焦虑等） | 是 |
| 咨询内容 | 具体描述想讨论的问题，帮助顾问提前准备 | 是 |
| 咨询形式 | 二选一：线上 / 线下 | 是 |
| 联系电话 | 用于必要时联系确认（两种形式均需填写） | 是 |
| 微信号 | 线上咨询时使用，线下咨询选填 | 线上必填，线下选填 |
| 线上会议链接 | 如已准备腾讯会议/其他链接可填写；如未提供，顾问将通过微信联系 | 线上选填，线下置灰 |

表单联动逻辑：

- 选择“线上”：电话必填 + 微信号必填 + 会议链接选填

- 选择“线下”：电话必填 + 微信号选填 + 会议链接不显示

B-3：预约记录

- 分页展示本人所有历史预约记录（含顾问姓名、时间、状态）

- 取消：咨询开始前4小时内禁止取消，取消后双方均收到邮件通知

模块C：朋辈顾问端

C-1：排期管理

- 支持两种排期方式：

- 批量上传：按模板导入每周/月排期

- 单个添加：灵活新增、修改或删除单个时段

- 可随时暂停/恢复某时段（如考试周或假期）

- 每个时段默认可预约人数为1人

- 可设置“暂不接待”状态，系统自动隐藏该时段

C-2：预约管理

- 查看所有报名自己的预约明细（含学生信息、咨询主题、时间）

- 预约开始前4小时内禁止取消，取消后双方均收到邮件通知可取消（需填写取消原因，系统自动通知学生）

- 咨询结束后，可标记状态为“已完成”

C-3：咨询反馈填写

- 针对已完成咨询，填写简要总结（如咨询主题、处理方式、是否需要跟进）

- 反馈内容仅管理员和顾问可见

C-4：数据导出

- 导出个人历史预约数据（Excel格式），便于个人存档或工作量汇报

模块D：管理端

D-1：顾问管理

- 创建 / 编辑 / 删除顾问账号

- 设置顾问基本信息（姓名、年级、专业、擅长方向、简介、照片）

- 设置顾问状态（启用 / 停用）

D-2：排期管理

- 查看所有顾问的排期

- 支持批量导入（按模板）

- 可代为调整任意顾问的排期

D-3：预约管理

- 查看所有预约记录，支持按顾问、日期、状态筛选

- 可查看每条预约的详细信息（学生、顾问、时间、咨询主题、线上/线下选择、联系方式）

D-4：咨询反馈与评价汇总

- 查看所有已完成咨询的反馈记录

- 支持按月 / 按顾问导出反馈汇总

D-5：数据统计与导出

- 统计维度：总预约数、完成数、取消数、各顾问咨询量排名

- 支持导出完整预约数据（Excel格式）

- 支持导出反馈评价汇总表

D-6：邮件通知配置

- 系统自动发送以下邮件：

- 预约成功通知（学生 + 顾问）

- 取消通知（双方）

- 预约提醒（咨询开始前1天，学生 + 顾问）

- 管理员可查看邮件发送记录

模块E：定时邮件自动化（服务器调度）

| 任务 | 触发条件 | 收件人 |
|---|---|---|
| 顾问提醒 | 每天 21:00，次日有预约 | 顾问 |
| 学生提醒 | 每天 21:00，次日有预约 | 学生 |
