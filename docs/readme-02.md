  - **功能模块详述**

*模块* *A**：登录与认证*

| **角色** | **方式** |
| --- | --- |
| 管理员 | 用户名 + 密码登录 |
| 朋辈顾问 | CUHK 统一身份认证 SSO 登录，首次登录自动建档，无需注册 |
| 学生 | CUHK 统一身份认证 SSO 登录，首次登录自动建档，无需注册 |

*模块* *B**：朋辈顾问端*

**B-1****：排期管理** - 支持两种排期方式： - 批量上传：按模板导入每周/月排期 - 单个添加：灵活新增、修改或删除单个时段 - 可随时暂停/恢复某时段（如考试周或假期） -每个时段默认可预约人数为 1 人 - 可设置”暂不接待”状态，系统自动隐藏该时段

**B-2：预约管理** - 查看所有报名自己的预约明细（含学生信息、咨询主题、时间） - 预约开始前 4 小时内禁止取消，取消后双方均收到邮件通知 - 咨询结束后，可标记状态为 ”已完成”

**B-3****：咨询反馈填写** - 针对已完成咨询，填写简要总结（如咨询主题、处理方式、是否需要跟进） - 反馈内容仅管理员和顾问可见

**B-4：数据导出** - 导出个人历史预约数据（Excel 格式），便于个人存档或工作量汇报

*模块* *C**：管理端*

**C-1****：顾问管理** - 创建 / 编辑 / 删除顾问账号 - 设置顾问基本信息（姓名、年级、专业、擅长方向、简介、照片） - 设置顾问状态（启用 / 停用）

**C-2****：排期管理** - 查看所有顾问的排期 - 支持批量导入（按模板） - 可代为调整任意顾问的排期

**C-3****：预约管理** - 查看所有预约记录，支持按顾问、日期、状态筛选 - 可查看每条预约的详细信息（学生、顾问、时间、咨询主题、线上/线下选择、联系方式）

**C-4****：咨询反馈与评价汇总** - 查看所有已完成咨询的反馈记录 - 支持按月 / 按顾问导出反馈汇总

**C-5****：数据统计与导出** - 统计维度：总预约数、完成数、取消数、各顾问咨询量排名 -支持导出完整预约数据（Excel 格式） - 支持导出反馈评价汇总表

**C-6：邮件通知配置** - 系统自动发送以下邮件： - 预约成功通知（学生 + 顾问） - 取消通知（双方） - 预约提醒（咨询开始前 1 天，学生 + 顾问） - 管理员可查看邮件发送记录

*模块* *D**：定时邮件自动化（服务器调度）*

| 任务 | 触发条件 | 收件人 |
| --- | --- | --- |
| 顾问提醒 | 每天 21:00，次日有预约 | 顾问 |
| 学生提醒 | 每天 21:00，次日有预约 | 学生 |
